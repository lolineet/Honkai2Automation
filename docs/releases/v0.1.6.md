# HKA v0.1.6

发布日期：2026 年 11 月 2 日

## 更新内容

- 新增无需按钮模板的邮件附件领取，识别“社交 → 我的消息”并检查领取结果；没有可领取附件时正常跳过。旧版标准邮件步骤自动升级，保留任务启用状态。
- 新增社团每日贡献奖励领取，自动进入“我的社团”，核对奖励后领取；已领取或未加入社团时跳过。标准日常配置自动在邮件任务后加入社团任务，已有自定义社团任务保持原样。
- 修复模拟器截图超时、连接关闭及 PNG 数据不完整的问题：仅重连当前设备，尝试兼容截图方式，并记住可用方式；重试有上限，支持停止。
- 配置了 MuMuManager 和明确实例编号时，连接前重新读取该实例的 ADB 地址，避免模拟器重启后沿用失效端口。
- 修复日常副本搜索滑动到固定推荐区的问题：切换活动页后，沿右侧活动列表双向搜索仍开放的难度 B 活动，并核对进入后的关卡地图。
- 补充全屏章节的房子图标和新版关卡返回按钮识别，兼容关卡地图保留上次停留位置。
- 返回首页后核对激活状态；点击未生效时重试，并区分角色首页与首页下的任务子页面，避免后续误点。
- 网页任务编辑器增加邮件附件、社团每日奖励流程选项。

## 验证与范围

- 186 项自动测试通过，覆盖邮件与社团领奖、旧配置升级、截图恢复、活动搜索、导航确认与取消操作等场景。
- 本机 MuMu + B服 + 1600×900 已验证邮件及社团流程；最近的导航修复已实测正确进入“机甲售卖会”、打开任务页及返回角色首页。
- 导航验证未执行战斗；本次发布不代表重新验证了所有日常任务的完整战斗流程。
- 发布流程将检查 Windows 免安装包、内置 ADB、OCR、中文及空格路径、首次配置与已有配置保留，通过后上传 ZIP。

## 使用与升级

下载 `HKA-Windows-x64.zip`，完整解压后双击 `打开助手.bat`。

升级前关闭旧助手的 BAT 启动窗口，备份并保留自己的 `config.json`、`templates/`、`state.json` 和 `runs/`，再启动新版。只刷新网页不会让旧服务加载新代码。

邮件任务默认关闭，需要时手动启用。标准日常配置会自动加入已启用的社团任务；自定义流程及已有社团任务不自动改写。
