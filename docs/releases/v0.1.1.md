# HKA v0.1.1

## 更新内容

- 新增启动时自动处理游戏资源更新和用户协议、隐私授权提示，无需配置。
- 适配 B服实际弹窗的“接受”和“快给我下”按钮；更新最多等待 15 分钟，期间可停止。
- 删除 VBS 启动入口，只保留前台 BAT 启动。关闭 BAT 窗口即停止服务和当前任务；关闭网页不会停止服务。
- Windows 免安装包继续内置 Python、依赖、OCR 模型和 ADB。

## 实测与验证

MuMu + B服 + 1600×900 实测：自动接受协议，确认下载 1480.1 MB 资源包，下载、解压后自动选择上次登录服务器并进入游戏。
测试未运行日常任务，登录后停在签到弹窗，未领取签到奖励。
89 项测试通过；发布流程另行检查 OCR 初始化、中文及空格路径、BAT 启动、配置保留和安装包不含 VBS。
其他渠道、安装包升级和不同授权文案尚未实测。

## 使用与升级

下载 `HKA-Windows-x64.zip`，完整解压后双击 `打开助手.bat`。
升级前退出旧服务，保留 `config.json`、`templates/`、`state.json`、`runs/`。
旧目录中的 `打开助手.vbs` 可删除，之后统一使用 BAT。
ADB 默认 `builtin`；多个模拟器时填写实际设备地址，唯一已连接的本地模拟器可使用 `auto`。
