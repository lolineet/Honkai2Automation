# HKA v0.1.8

发布日期为 2026 年 11 月 22 日。

## 更新内容

- 为导航、画面识别、体力读数、领奖结果和战斗结算等卡顿相关检查加入三次尝试。每次尝试允许等待画面稳定，耗尽后停止本轮后续任务，并通过已配置的邮件或 Webhook 发送失败通知。
- 重试保留当前流程的领奖与战斗进度。兑换后重新读取体力变化，战斗等待继续核对同一场战斗，单次武器输入保持每局一次。
- 修复任务面板左侧按钮位置变化引起的“未进入首页任务页面”，使魔探险、存在感和每周任务改为在左侧面板按文字识别入口。
- 修复宁蒂生日回复台词遮挡标题及日期时无法识别领取弹窗的问题，支持从已打开的生日奖励弹窗继续领取。
- 修复双倍体力兑换耗尽后顶部余额消失导致的误报。持续只显示普通体力时跳过额外 BONUS，兑换后通过已核对的兑换数量和普通体力增量确认结果。
- 改善战斗中 ADB 连接关闭或设备离线时的恢复，重连后核对设备、游戏前台和战斗画面，再继续当前战斗。
- 改善邮件页标题误识别及首次通关结算按钮识别。

## 验证

- 219 项自动测试通过，覆盖三次尝试、耗尽后停止后续任务、失败通知调用、延迟页面和模拟器启动恢复。
- 已在本机 Windows、MuMu、B服、1600×900 环境确认生日领奖、断线战斗续接和任务面板导航。最近一次补跑完成使魔探险、存在感、每周奖励、3 局 BONUS 及最终领奖。
- 发布工作流检查 Windows 免安装包、内置 ADB、OCR、中文和空格路径、首次配置及已有配置保留，通过后上传 ZIP。

## 使用与升级

下载 `HKA-Windows-x64.zip`，完整解压后双击 `打开助手.bat`。

升级前关闭旧助手，备份并保留自己的 `config.json`、`templates/`、`state.json` 和 `runs/`，再启动新版服务。已有通知收件人与授权码沿用原配置，失败通知需要可用的邮件或 Webhook 配置。
