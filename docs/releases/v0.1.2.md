# HKA v0.1.2

## 更新内容

- 每日签到和随后出现的连登奖励合并为“签到与连登奖励”流程，自动识别并连续领取，无需按钮模板。
- 支持直接从连登奖励页面开始；没有奖励弹窗时自动结束。
- 领取后检查页面变化，避免网络等待时反复点击同一张奖励页；支持停止操作。
- 默认配置启用该流程，任务 ID 仍为 `signin`。界面可添加 `claim_login_rewards` 游戏流程。

## 验证

MuMu + B服 + 1600×900 实测：从“烈火新生连登福利”页面开始，领取成功，确认奖励页消失后结束。
每日签到当时已经领取，签到后接连登的完整顺序由回归测试覆盖。
97 项测试通过，覆盖连续领取、直接从连登页开始、没有奖励、误点防护、页面卡住和停止操作。
发布流程另行检查 BAT、内置 ADB、OCR、中文及空格路径和配置保留，安装包不包含 VBS。

## 使用与升级

下载 `HKA-Windows-x64.zip`，完整解压后双击 `打开助手.bat`。关闭 BAT 窗口即停止服务。
升级前退出旧服务，保留 `config.json`、`templates/`、`state.json` 和 `runs/`。
旧配置不会被覆盖；使用旧配置时，将 `signin` 任务的步骤替换为下面内容并启用任务：

```json
[{"type": "game_flow", "flow": "claim_login_rewards"}]
```

该流程保留原任务 ID，可保留已有完成记录。
