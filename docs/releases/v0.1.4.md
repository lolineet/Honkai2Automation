# HKA v0.1.4

## 更新内容

- 修复部分模拟器启动游戏时报 `/system/bin/sh: monkey: inaccessible or not found`，导致每日流程中断的问题。
- 优先通过 Android 包管理器查找游戏启动入口并直接启动，兼容不同渠道的游戏包；旧版启动方式保留为兼容回退。
- 启动失败时显示包名检查提示并保留各次尝试的错误详情，避免将返回成功退出码的启动错误误判为成功。

## 验证

- 121 项自动测试通过，覆盖缺少 monkey 时的启动、旧版包管理命令兼容、启动失败提示和取消操作。
- 发布流程检查 Windows 免安装包的 BAT 启动、内置 ADB、OCR、中文及空格路径、首次配置与配置保留。
- 尚未在反馈问题的用户模拟器上实测。

## 使用与升级

下载 `HKA-Windows-x64.zip`，完整解压后双击 `打开助手.bat`。

升级前退出旧 BAT 服务，保留自己的 `config.json`、`templates/`、`state.json` 和 `runs/`。无需修改任务配置即可使用此次启动修复。
