# HKA v0.1.3

## 更新内容

- 修复使魔的爱和虚轴之庭快捷战斗报“活动列表未找到多元裂缝”：先切换活动页，再双向查找，兼容列表保留滚动位置；缩短滑动步长，进入后核对关卡地图。
- 自动检测装备仓库已满，显示需要处理提醒、保存现场截图并停止后续任务；不会自动出售、合成或扩容，也不会自动重试满仓任务。
- 邮件通知默认使用 QQ 邮箱，填写 QQ 号和 SMTP 授权码即可向自己发送提醒，提供测试邮件按钮；保留自定义 SMTP 和原有通知开关。
- SMTP 授权码由 Windows 当前账户加密保存，网页不返回授权码，留空保存可保留已有授权码。

## 验证

- 116 项自动测试通过，覆盖列表双向查找、入口缺失、地图核对、满仓中断、通知发送和授权码保护等场景。
- MuMu + B服 + 1600×900 实测：两个关卡均成功进入详情页，识别使魔的爱剩余 1 次、虚轴之庭免费剩余 6 次；本次导航测试未执行战斗或消耗资源。
- 真实装备满仓弹窗验证通过，检测后停止后续任务并保存截图，未操作装备。
- QQ 邮件通过模拟 SMTP 验证 SSL、收发给自己及错误隐藏授权码；未使用真实邮箱发送，填写后可点击测试邮件检查实际连接。
- Windows 免安装包检查覆盖 BAT、内置 ADB、OCR、授权码加解密、中文及空格路径和配置保留；不包含 VBS、个人配置、授权码或游戏截图。

## 使用与升级

下载 `HKA-Windows-x64.zip`，完整解压后双击 `打开助手.bat`。关闭 BAT 窗口即停止服务。

升级前退出旧 BAT 服务，保留自己的 `config.json`、`templates/`、`state.json` 和 `runs/`。新版本不会覆盖已有配置；无需修改任务配置即可使用导航修复和满仓检测。

需要邮件提醒时，在通知页面选择 QQ 邮箱，填写 QQ 号和 QQ 邮箱的 SMTP 授权码，启用并保存，再点击测试邮件。授权码不是 QQ 登录密码。旧服务不支持安全保存授权码，必须先退出旧 BAT，再启动新版。

授权码绑定当前 Windows 账户。更换电脑或 Windows 账户后，需要重新填写并保存授权码。
