# HKA v0.1.7

发布日期：2026 年 11 月 5 日

## 更新内容

- 将战斗配置统一为 A/B/C 三个射击键，对应装备页从左到右的武器槽；默认战斗位置分别为左下、右下、右上。移除独立的第四个“射击”入口，避免额外输入与武器方案冲突。
- 兼容旧版 `shoot` / `skills` 配置，纠正原先指向角色或使魔技能的默认坐标，保留自行校准的坐标。启用的旧 A/B/C 方案优先；新配置全部关闭时不会隐式射击。
- 网页明确区分循环点按、循环长按、仅进图一次和关闭，支持调整每轮移动/等待时长及校准坐标。同一任务中的多个战斗步骤可以分别编辑。
- 日志记录每轮成功发送的武器点按与长按，便于检查输入是否重复执行。点按每轮执行一次，实际间隔包含识图、其他按键和移动/等待耗时。
- 修复 BONUS 已胜利却因小范围 OCR 找不到“确定”而报错的问题：在完整画面中核对结算标题、再次挑战与确定按钮；导航可恢复遗留的结算页面。
- 战斗识图前与武器输入前检查游戏前台包名；游戏离开前台或状态不明时停止战斗输入。输入被模拟器拒绝时明确显示失败的操作及 `INJECT_EVENTS` 错误，不自动重放可能已部分执行的输入。

## 验证与范围

- 200 项自动测试通过，覆盖配置迁移、A/B/C 对应关系、循环与单次输入、关闭行为、结算确认、前台丢失及输入错误处理。
- 本机 Windows + MuMu + B服 + 1600×900 已完成一轮每日检查，发现问题修复后续跑完成：签到、社团、共鸣屋、零时馈礼、免费快捷战斗、普通与双倍 BONUS、使魔探险、存在感及补刷。邮箱和每周任务无可领取奖励时正常跳过。
- 已实战确认循环点按、循环长按和修复后的结算确认。游戏曾离开前台，具体原因仍未确认；本版增加停止输入保护，不代表解决了所有模拟器权限问题。
- 发布工作流通过测试、免安装包构建及隔离检查后上传 Windows x64 ZIP；检查覆盖内置 ADB、OCR、中文和空格路径、首次配置及已有配置保留。

## 使用与升级

下载 `HKA-Windows-x64.zip`，完整解压后双击 `打开助手.bat`。

升级前关闭旧助手的 BAT 启动窗口，备份并保留自己的 `config.json`、`templates/`、`state.json` 和 `runs/`，再启动新版。只刷新网页不会让旧服务加载新代码。

首次加载会将旧战斗配置转换为 A/B/C 武器配置，保存时写入新格式。升级后请核对各阶段的武器模式；自定义游戏按键布局需要自行校准坐标。
