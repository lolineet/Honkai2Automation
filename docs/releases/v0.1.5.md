# HKA v0.1.5

## 更新内容

- 角色生日奖励并入每日签到、连登领奖流程：自动识别生日界面，点击“生日快乐”，再领取祝福奖励，无需配置生日日期、模板或单独启用生日任务。
- 已有 `claim_login_rewards` 签到流程自动获得生日领奖能力；默认配置移除旧的生日邮件模板示例。
- 登录后遇到签到、连登或生日界面时，继续进入领奖流程，避免被遮挡的首页入口导致进入游戏超时。
- 修复默认 8765 端口被其他程序占用时，双击助手闪退的问题：自动选择空闲端口并打开实际页面，重复双击可打开当前助手页面。
- 启动失败时保留 BAT 窗口中的错误信息，方便反馈问题。

## 验证

- 133 项自动测试通过，覆盖生日祝福与领取、从领取弹窗继续、重复画面不连点、按钮缺失、取消操作以及端口冲突处理。
- MuMu + B服 + 1600×900 实测：领取希儿生日奖励后返回首页；真实界面 OCR 回放验证祝福和领取两步操作。
- 本机实际 BAT 验证：8765 被另一工具占用时可启动，网页返回正常，重复启动打开同一助手地址。
- 发布流程检查免安装包的 BAT、内置 ADB、OCR、中文及空格路径、首次配置和配置保留。

## 使用与升级

下载 `HKA-Windows-x64.zip`，完整解压后双击 `打开助手.bat`。

升级前退出旧 BAT 服务，保留自己的 `config.json`、`templates/`、`state.json` 和 `runs/`。已有签到与连登领奖流程无需修改即可自动领取生日奖励。

默认端口被占用时，请使用双击助手自动打开的页面，或 BAT 窗口中显示的实际地址。
